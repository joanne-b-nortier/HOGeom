# Latent geometry organizes higher-order interactions

1. Set up a virtualenv and install required packages using `requirements.txt`

2. Download and install the *geometric-randomization* repo from 
[here](https://github.com/networkgeometry/b-mercator/tree/main).



3. Figures for the main text can be generated using code in `code-for-figures.ipynb`

4. Data can be downloaded from Hypergraphx-data, which may be found [here](https://hgx-team.github.io/hypergraphx-data/).
